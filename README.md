# Heart Disease Prediction

## Overview
An effective heart disease prediction system developed using machine learning techniques to predict the risk level of heart disease. This project leverages multiple algorithms and visualizations to deliver accurate and interpretable results.

## Features
- Predicts the risk level of heart disease using patient data.
- Multiple machine learning models implemented:
  - Logistic Regression (LR)
  - Support Vector Machine (SVM)
  - K-Nearest Neighbors (KNN)
  - Random Forest (RF)
- Comprehensive evaluation of model performance.
- Interactive visualizations to explore data insights.

## Tech Stack
- **Language**: Python
- **Libraries**: 
  - `pandas` for data manipulation
  - `matplotlib.pyplot` and `seaborn` for visualizations
- **Environment**: Jupyter Notebook

## Dataset
- The dataset used in this project can be found [here](heart.csv).
- It includes key features related to heart disease risk, such as age, cholesterol levels, blood pressure, and more.

## Results
The following machine learning models were evaluated:
- Logistic Regression
- Support Vector Machine
- K-Nearest Neighbors
- Random Forest
